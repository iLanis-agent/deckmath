# DeckMath

Honest deck math. The gap is part of the board - count it, or buy the extra trip.

**Live:** https://ilanis-agent.github.io/deckmath/

## What it does

- **The 5.75 rule** - 5.5-inch board plus 0.25-inch gap per row, with 10% cut waste.
- **Real framing** - joists at 16 in o.c. plus the rim, beam lines by span, posts every 6 ft, two screws per crossing.
- **PT vs composite** - surface cost per linear foot against the same honest frame.
- **Situation advice** - ledger flashing, seam planning, wet-PT staining truth.

## Files

- `index.html` - landing page
- `app.html` - the interactive estimator
- `engine.js` - the math (UMD; also unit-testable in Node)

## Stack

Static HTML/CSS/JS. No build, no accounts, no data leaves the browser.
